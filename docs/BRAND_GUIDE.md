# Brand Execution Guide

This repository treats brand as structured production data rather than a loose mood board. The visual language should remain recognizable while allowing each ichoTaKu content family to breathe differently.

## Shared DNA

Across profiles, preserve these traits:

- high contrast
- deliberate typography
- strong focal hierarchy
- creator-built rather than corporate-polished energy
- visible systems thinking: grids, signals, diagrams, cards, timelines, annotations
- selective texture rather than indiscriminate noise
- recurring signal / radio / waveform language where appropriate
- intentional use of magenta, cyan, warm amber, black, cream, and game-context tones

## `ichotaku_default`

Use for creator commentary, automation, AI workflows, code demos, and project updates.

Visual behavior:

- dark field with restrained hot-pink and cyan accents
- clean captions with occasional handwritten or markup emphasis
- terminal, waveform, graph, and workflow motifs
- punchy cuts and purposeful zooms
- avoid generic SaaS gradients and generic AI-glow overload

## `digitaldive`

Use for research, explainers, frameworks, and knowledge systems.

Visual behavior:

- structured information cards
- diagrams and evidence trails
- cleaner motion than Heartbreak Alley
- technical cyan accents
- dense information only when hierarchy remains obvious

## `heartbreak_alley`

Use for Trashcat anthology, Love Is Rubbish, punk-poetic lore, and emotionally charged visual stories.

Visual behavior:

- black / charcoal ground
- hot pink and cyan as signal colors
- cream paper, amber moonlight, orange fire when warmth is needed
- distressed zine panels, collage edges, brush lettering, radio towers, moons, crowns, hearts, alley textures
- raccoon characters should feel like a recurring cast rather than random mascot substitutions
- motion can use panel reveals, pasted-paper cuts, parallax, flicker, and deliberate roughness

Do not flatten this profile into generic cyberpunk neon. The tension between handmade folk/zine warmth and electric punk/cyber signal is part of the identity.

## `eso_gaming`

Use for ESO gameplay, guides, discoveries, build notes, and creator-history clips.

Visual behavior:

- gameplay remains the hero
- overlays should explain rather than cover action
- use map markers, quest-card logic, timing indicators, loot tags, and concise callouts
- preserve readable game UI where it carries useful context
- brand identity lives in framing, captions, and intro/outro behavior rather than constantly masking the footage

## Caption rules

Captions should be readable first and styled second.

Default guidance:

- maximum 2 lines when possible
- strong contrast against moving footage
- avoid covering faces, combat telegraphs, UI prompts, or focal art
- emphasize only a few words at a time
- retain punctuation when it improves the creator voice

## Safe-zone policy

For 1080x1920 vertical output, keep critical text and logos away from platform UI regions. The exact platform overlays can change, so the renderer should eventually enforce named safe-zone presets rather than hardcoding a single permanent crop assumption.

## Generated visual policy

Generated assets should extend existing series DNA. Before generation, include:

- series/profile
- palette family
- recurring motifs
- character identity constraints
- composition role in the reel
- relationship to existing archive assets

Prompt text alone is not the brand system. Preserve references, generated asset metadata, and source relationships so future outputs can remain consistent.
